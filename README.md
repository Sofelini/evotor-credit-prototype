# Кредит для бизнеса в приложении Эвотор — прототип

Кликабельный прототип двух сценариев пилота:

- **A · Быстрый пилот** — баннер на «Сводке» → форма в WebView → менеджер (SMS, звонок, документы по ссылке).
- **B · Нативное приложение** — форма, статус, паспорт, выписки и подписание внутри приложения, заявки в CRM Эвотора.

Цифры, банки и условия на экранах условные. Тексты, обведённые пунктиром, ещё в работе.

## Как открыть

Откройте `index.html` в браузере — сборка и установка не нужны.

Прямые ссылки на шаги работают через якорь: `#a1` … `#a8`, `#b1` … `#b15`
(например, `…/index.html#b2` — нативная форма).

## Публикация на GitHub Pages

Проще всего — скриптом `publish.command`:

1. Распакуйте архив.
2. Откройте **Терминал** (Spotlight: ⌘ + пробел → «Терминал»).
3. Напечатайте `bash` и пробел, перетащите в окно файл `publish.command`, нажмите **Enter**.

Скрипт сам установит GitHub CLI (если его нет), попросит войти в GitHub через браузер,
создаст публичный репозиторий `evotor-credit-prototype`, загрузит файлы, включит Pages
и покажет ссылку вида `https://<логин>.github.io/evotor-credit-prototype/` — она же скопируется в буфер.
Повторный запуск обновляет уже опубликованную страницу.

Страница закрыта от поисковиков (`noindex`), но открыта всем, у кого есть ссылка.
